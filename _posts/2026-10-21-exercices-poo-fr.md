  Exercices sur les concepts de POO, le polymorphisme, l’héritage, les classes abstraites, les génériques, Java et les comptes bancaires.
---

1. Rédige un tutoriel expliquant comment représenter les concepts fondamentaux de la programmation orientée objet dans le langage de ton choix, autre que Java.

2. Décris le polymorphisme, son fonctionnement et son impact sur la programmation système, avec ses avantages et ses inconvénients. Donne un exemple.

3. Définis la redéfinition (*overriding*) et la surcharge (*overloading*) de méthodes dans les langages orientés objet. Donne des exemples.

4. Définis l’héritage et décris trois situations dans lesquelles il serait approprié. Ajoute un exemple de code.

5. Que sont les classes abstraites et à quoi servent-elles dans les langages orientés objet ? Décris au moins trois situations où elles seraient appropriées.

6. Quels sont les avantages des types génériques dans les systèmes orientés objet et quand faut-il les utiliser ? Donne au moins trois exemples de situations où ce mécanisme est utile.

7. Considère les affirmations suivantes sur la programmation orientée objet :

   I. Les méthodes définissent les opérations des classes.

   II. Les classes sont des abstractions qui représentent des concepts du monde réel et du monde informatique.

   III. Les instances de classes sont généralement créées au moyen de constructeurs, qui créent des objets d’une classe donnée.

   Choisis la bonne réponse :

   1. Seule l’affirmation I est incorrecte.
   2. Seule l’affirmation II est incorrecte.
   3. Seule l’affirmation III est incorrecte.
   4. Seules les affirmations I et III sont incorrectes.
   5. Aucune affirmation n’est incorrecte.

8. Choisis l’affirmation correcte sur l’héritage en Java :

   1. Un objet de superclasse peut toujours être affecté à une variable dont le type est l’une de ses sous-classes sans erreur de compilation.
   2. L’héritage est le seul moyen d’accéder aux méthodes et champs depuis l’extérieur d’une classe.
   3. Il est impossible de remplacer complètement le comportement d’une méthode de superclasse ; on ne peut que l’étendre.
   4. La surcharge définit plusieurs méthodes ayant les mêmes paramètres dans une superclasse afin que ses sous-classes puissent les utiliser.
   5. Une sous-classe hérite de tous les champs et méthodes non privés de sa superclasse et peut ajouter de nouveaux champs et méthodes.

9. Crée des classes permettant de gérer des comptes bancaires. Les comptes peuvent être des comptes d’épargne ou des comptes courants. Il doit être possible de :

   - Consulter le solde d’un compte.
   - Modifier le solde d’un compte.
   - Retirer de l’argent d’un compte.
   - Déposer de l’argent sur un compte.
   - Transférer de l’argent vers un autre compte.
   - Bloquer et débloquer un compte, par exemple avec `account1.block()` et `account1.unblock()`. Si un compte est bloqué, seul son solde peut être lu ou modifié.

10. Implémente le jeu *Démineur* en Java dans le terminal.
