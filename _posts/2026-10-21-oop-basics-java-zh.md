结构化编程通过定义数据结构及操作这些结构的算法，提供了模块化软件系统概念的机制。常见的结构化语言可以表示不同的数据类型和变量，以表达相关概念的特征与属性，也可以使用过程和函数来建模相应操作。

然而，要复用结构化语言中编写的组件，我们需要识别数据（由数据结构、数据类型和变量表示）与行为（由过程和函数表达）之间的关系。因此，复用通常发生在较细粒度的层次，并且往往需要大量工作，例如判断哪些过程和函数与哪些数据结构相关。虽然可以定义可复用库，但数据和行为之间的关系并不明确，也没有集中在单一抽象中。

**面向对象编程**（OOP）是一种编程范式，它通过称为类的抽象数据类型来表示特定应用领域中的概念。类既建模这些概念的特征和属性，也建模它们的操作。OOP 扩展了结构化编程，提供了定义和组合类的方式，用于建模完整的计算机系统，从而提高模块化程度并复用组件。

如今，面向对象编程是软件开发中最广泛接受和使用的范式之一。许多现代语言都支持它，包括 Java、C++、C#、Python、Kotlin、JavaScript、TypeScript、Swift 和 Ruby。

**类**是一种抽象机制，用于表示特定应用领域中的概念。例如，在银行领域中，概念可能包括分行、账户、客户和交易。我们可以定义 `Branch`、`Account`、`Customer` 和 `Transaction` 等类来表示它们。图中展示了这些类的图形化表示。

类充当*模板*，用于创建这些概念的具体、可操作实例。这些实例称为**对象**。对象是类的一个**实例**，创建对象的过程称为**实例化**。例如，我们可以创建表示客户 *John*、*Peter* 和 *Mary* 的对象，并包含他们的个人信息和客户可用的功能。

<img src="/images/en/oopObjects.svg" alt="John、Peter 和 Mary 对象分别是 Customer 类的实例。" style="max-width: 380px; width: 100%; height: auto; display: block; margin: 20px auto;"/>

类的定义用于表示某个概念的属性、特征和行为。主要机制是属性和方法。

**属性**表示类中对象的特征或属性。`Customer` 类的属性可以包括 *name*、*age*、*address* 和 *marital status*。每位客户的属性值可能不同。例如，某个客户对象可以有以下值：*name* $`=`$ John Smith，*age* $`=`$ 50，*address* $`=`$ 205 President Vargas Street，*marital status* $`=`$ married。

**方法**表示行为。`Account` 类的可能方法可以对应账户的*开户*、*销户*或*更改账户持有人*等操作。**调用**方法（也称为**调用执行**）会执行该方法实现的操作。类通常包含用于创建（实例化）对象的特殊方法，称为**构造器**；也可能包含用于销毁对象的**析构器**。

属性和方法还分为实例成员和类成员。最常见的**实例属性和实例方法**通过类的对象访问，表示与各个实例相关的特征和操作。`Account` 的实例属性可以包括 *bank*、*branch*、*account number* 和 *account holder*；实例方法可以包括 *withdraw*、*transfer* 和 *deposit*。而**类属性和类方法**属于类本身，而不是其实例。例如，类属性可以统计已创建的 `Account` 实例数量，类方法则可以返回该数量。

为了限制对属性和方法的访问，类提供了**封装和信息隐藏**机制。编程语言通常提供可见性修饰符，用来指定哪些代码可以访问特定属性、方法或类。

类是抽象机制，用于表示并封装现实世界和计算机世界中的概念。我们可以通过各种关系组合这些抽象，使类协同工作以满足应用需求。类之间的主要关系包括继承、关联、聚合、组合和实现。

**继承**是一种组合机制，使类能够复用现有类的接口和行为，并扩展其功能。扩展另一个类的类称为**子类**，被扩展的类称为**超类**。通常在子类中声明扩展关系，例如 `SubClass` 扩展 `SuperClass`。

<img src="/images/en/oopInheritance.png" alt="Shape 是 Rectangle、Triangle 和 Circle 的超类。" style="max-width: 400px; width: 100%; height: auto; display: block; margin: 20px auto;"/>

不同编程语言的继承机制有所不同，差异通常涉及可见性和继承的数量。一些语言（例如 C++）允许指定**公有继承**或**私有继承**。假设类 `B` 继承类 `A`。那么 `A` 是 `B` 的超类，`B` 是 `A` 的子类。采用公有继承时，`B` 是 `A` 的子类型，并继承 `A` 的实现和接口。在需要 `A` 对象的任何位置，都可以使用 `B` 对象（或 `A` 的其他子类对象），因为每个 `B` 实例也被视为 `A` 的实例。这一原则称为**里氏替换原则**。采用私有继承时，`B` 并不是 `A`；它只继承 `A` 的实现，并以 `A` 为基础构建。此时里氏替换原则不适用。

继承还可以分为**单继承和多继承**。Java 和 C# 采用单继承，一个类只能有一个超类。C++ 等语言采用多继承，一个类可以有多个超类。语言设计者对于多继承的收益是否足以抵消相关问题并无共识。其他语言提供了替代方案，例如基于接口的虚拟继承、*trait* 和 *mixin*。

图 4 展示了多继承的例子。`Mammal` 和 `Bird` 表示动物。`Horse`、`Dog` 和 `Bat` 是 `Mammal` 的子类，`Ostrich` 和 `Duck` 是 `Bird` 的子类。我们还希望分类能够飞行的动物，因此创建 `Flyer` 类来表示不一定是动物的飞行对象。通过多继承，`Duck` 和 `Bat` 对象也可以继承 `Flyer`，成为飞行对象。

有些类是**抽象类**。它们与**具体类**一样，表示一组现实世界对象的特征和行为，但不能直接实例化。在多继承示例中，`Mammal`、`Bird` 和 `Flyer` 可以是抽象类，因为现实世界中只有它们子类的实例，例如马、狗和鸭子。

除了可见性和继承数量，继承还允许创建多态方法。在面向对象编程中，**多态**是指一个操作能够根据调用它的对象所属类而表现出不同的行为。主要形式包括：

- **特设多态（或重载）**：一个类中存在名称相同但形式参数类型不同的方法。实际使用的参数决定调用哪个方法。
- **参数化多态**：方法以泛型方式创建，并绑定到稍后才确定的类型，例如声明变量或实例化对象时。在面向对象语言中，这类类型称为泛型类型。
- **子类型多态**：子类重写超类的方法。调用方法的对象决定执行哪个实现，通常通过运行时动态绑定来确定。

除继承外，还有关联、聚合和组合等关系。一般而言，它们的区别在于参与对象之间的耦合程度：

- **关联**中的对象关系通常是临时的，可以在运行时轻松更改。例如，在交通系统中，一个人可以作为驾驶员与某辆车关联。更换驾驶员并解除关联后，两个对象仍然存在。
- **聚合**比关联更强。被聚合的对象通常与聚合对象一同创建。例如，汽车有四个车轮：汽车是聚合对象，车轮是被聚合对象。关系可以解除，但更换车轮通常比更换驾驶员少见，也更费事。
- **组合**的关系更强，因为组成对象是更大对象的一部分。例如，车辆座椅的织物由线组成。如果这些线不复存在，座椅也不复存在，或至少失去原有特性。

对象之间的这些关系往往是概念性的。映射到编程语言时，可以通过类属性关联、聚合或组合对象，并在运行时为属性赋值。对象的创建时机也可能不同：组合中的组成对象通常在整体的构造器中创建；关联中的对象通常独立创建，并在需要时建立联系。

最后一种关系是**实现**，它发生在类声明自己实现某个接口时。**接口**可以看作所有方法都是抽象方法的抽象类[^1]。接口充当客户端与实现者之间的协议。类（或其某个子类）必须实现接口中声明的方法。这样，客户端可以编写符合接口的代码，而不必依赖实现类的具体方式。

[^1]: 从 Java 8 开始，接口也可以定义具体方法，例如使用 `default` 关键字声明的默认方法。实现包含默认方法的接口时，类不必自行实现该方法，但可以选择重写它。
