1. Java가 아닌 원하는 언어로 객체 지향 프로그래밍의 기본 개념을 표현하는 방법을 설명하는 튜토리얼을 작성하세요.

2. 다형성이 무엇이고 어떻게 발생하는지, 시스템 프로그래밍에 어떤 영향을 주는지 장점과 단점을 포함해 설명하세요. 예를 드세요.

3. 객체 지향 프로그래밍 언어에서 메서드 오버라이딩과 메서드 오버로딩을 정의하고 예를 드세요.

4. 상속을 정의하고 적절한 사용 사례 세 가지를 설명하세요. 코드 예제를 포함하세요.

5. 추상 클래스란 무엇이며 객체 지향 프로그래밍 언어에서 어떤 용도로 사용되나요? 추상 클래스가 적절한 상황을 적어도 세 가지 설명하세요.

6. 객체 지향 시스템에서 제네릭 타입을 사용하면 어떤 장점이 있고 언제 사용해야 하나요? 이 메커니즘이 유용한 상황을 적어도 세 가지 드세요.

7. 객체 지향 프로그래밍에 관한 다음 문장을 살펴보세요.

   I. 메서드는 클래스의 연산을 정의합니다.

   II. 클래스는 현실 세계와 컴퓨팅 세계의 개념을 표현하는 추상화입니다.

   III. 클래스 인스턴스는 일반적으로 특정 클래스의 객체를 생성하는 생성자로 만들어집니다.

   올바른 답을 선택하세요.

   1. I만 틀렸습니다.
   2. II만 틀렸습니다.
   3. III만 틀렸습니다.
   4. I과 III만 틀렸습니다.
   5. 틀린 문장은 없습니다.

8. Java 상속에 관한 올바른 문장을 선택하세요.

   1. 상위 클래스 객체는 컴파일 오류 없이 항상 하위 클래스 타입 변수에 할당할 수 있습니다.
   2. 클래스 외부에서 메서드와 필드에 접근하는 유일한 방법은 상속입니다.
   3. 상위 클래스 메서드의 동작은 완전히 바꿀 수 없고 확장만 가능합니다.
   4. 오버로딩은 하위 클래스가 사용할 수 있도록 상위 클래스에 같은 매개변수를 갖는 여러 메서드를 정의하는 것입니다.
   5. 하위 클래스는 상위 클래스의 모든 비공개가 아닌 필드와 메서드를 상속하며, 새 필드와 메서드를 추가할 수 있습니다.

9. 은행 계좌를 관리하는 클래스를 만드세요. 계좌는 저축 계좌 또는 당좌 계좌일 수 있습니다. 다음 기능을 제공해야 합니다.

   - 계좌 잔액 조회.
   - 계좌 잔액 변경.
   - 계좌에서 출금.
   - 계좌에 입금.
   - 다른 계좌로 송금.
   - `account1.block()`과 `account1.unblock()`처럼 계좌를 차단하고 차단 해제. 계좌가 차단된 경우 잔액만 읽거나 변경할 수 있습니다.

10. Java 터미널용 *지뢰 찾기* 게임을 구현하세요.
