Schreiben Sie Java-Programme für die zehn Übungen aus dem ersten Kapitel des Buches.

1. Lesen Sie zwei ganze Zahlen ein und geben Sie Summe, Differenz, Produkt und Quotient aus.
2. Lesen Sie zwei reelle Zahlen als Seiten eines Rechtecks ein und berechnen Sie Fläche und Umfang.
3. Lesen Sie drei ganzzahlige Seitenlängen ein. Prüfen Sie, ob sie ein Dreieck bilden. Klassifizieren Sie es gegebenenfalls als gleichseitig, gleichschenklig oder ungleichseitig; andernfalls geben Sie eine entsprechende Meldung aus.
4. Lesen Sie die Koeffizienten `a`, `b` und `c` von `ax² + bx + c = 0` ein. Berechnen Sie `Δ = b² − 4ac`. Ist `Δ` negativ, melden Sie, dass keine reellen Lösungen existieren; andernfalls berechnen Sie die Lösungen mit `x = (−b ± √Δ)/(2a)`.
5. Lesen Sie zehn ganze Zahlen ein, berechnen Sie ihren Mittelwert und geben Sie die darüber liegenden Werte aus.
6. Lesen Sie ganze Zahlen bis zur Eingabe von null ein. Geben Sie die Anzahl gerader Zahlen, den Mittelwert ungerader Zahlen, die größte gerade Zahl und die Anzahl ungerader Zahlen aus, die größer als diese sind.
7. Initialisieren Sie eine Collection mit zehn Ländernamen. Lesen Sie eine `String` ein und prüfen Sie, ob ein Name genau übereinstimmt; geben Sie außerdem Namen aus, die den eingegebenen Text enthalten.
8. Geben Sie das Einmaleins von `1 x 1 = 1` bis `9 x 9 = 81` aus.
9. Lesen Sie eine ganze Zahl ein und zählen Sie einschließlich null rückwärts. Bei Eingabe von `5` soll die Ausgabe `5 4 3 2 1 0` enthalten.
10. Zeigen Sie ein Menü mit drei Optionen und einer vierten zum Beenden. Geben Sie bei den ersten drei Optionen die Auswahl aus und wiederholen Sie die Interaktion. Beenden Sie das Programm bei Auswahl der vierten Option.
