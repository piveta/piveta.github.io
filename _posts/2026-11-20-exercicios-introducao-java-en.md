Write Java programs to solve the ten exercises from the book's first chapter. This page gives the problems without ready-made solutions.

1. Read two integers and display their sum, difference, product, and quotient.

2. Read two real numbers representing the sides of a rectangle and calculate its area and perimeter.

3. Read three integer side lengths. Determine whether they can form a triangle. If so, classify it as equilateral, isosceles, or scalene; otherwise, report that they do not form a triangle.

4. Read the coefficients `a`, `b`, and `c` of `ax² + bx + c = 0`. Calculate `Δ = b² − 4ac`. If `Δ` is negative, report that there are no real roots; otherwise, calculate and display both roots using `x = (−b ± √Δ)/(2a)`.

5. Read ten integers. Calculate their average and display only the values greater than that average.

6. Read integers until zero is entered. Display how many even numbers were read, the average of the odd numbers, the greatest even number, and how many odd numbers exceed that greatest even number.

7. Initialize a collection with ten country names. Read a `String` and traverse the collection: report whether any name exactly matches the input, and display all names containing it.

8. Display multiplication tables from 1 through 9, from `1 x 1 = 1` to `9 x 9 = 81`.

9. Read an integer and count down to zero, inclusive. For input `5`, the output should include `5 4 3 2 1 0`.

10. Display a menu with three options and a fourth option to exit. For the first three, show the selected option and repeat the interaction. Stop only when the exit option is selected.
