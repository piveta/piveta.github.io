编写 Java 程序，完成本书第一章的十道练习。

1. 读取两个整数，输出它们的和、差、积与商。
2. 读取表示矩形两边的两个实数，计算面积和周长。
3. 读取三个整数边长，判断能否构成三角形；若能，判断是等边、等腰还是不等边三角形，否则输出提示。
4. 读取方程 `ax² + bx + c = 0` 的系数 `a`、`b`、`c`，计算 `Δ = b² − 4ac`。若 `Δ` 为负，提示没有实根；否则用 `x = (−b ± √Δ)/(2a)` 计算并输出实根。
5. 读取十个整数，计算平均值并输出大于平均值的数。
6. 不断读取整数，直到输入零。输出偶数个数、奇数平均值、最大偶数，以及大于最大偶数的奇数个数。
7. 用十个国家名称初始化一个集合。读取一个 `String`，判断是否有名称与输入完全相同，并输出包含该文本的国家名称。
8. 输出从 `1 x 1 = 1` 到 `9 x 9 = 81` 的乘法表。
9. 读取一个整数，倒数至零（包括零）。输入 `5` 时，输出应包含 `5 4 3 2 1 0`。
10. 显示一个含三个选项和第四个退出选项的菜单。选择前三项时，显示所选项并继续交互；选择退出时结束。
